# GPT Chat Room - 開發檢查清單

## 環境設定檢查

### 必要軟體
- [ ] PHP 8.2 或更高版本
- [ ] Node.js 18 或更高版本
- [ ] Composer
- [ ] npm 或 yarn
- [ ] SQLite 支援

### 環境變數設定
- [ ] `OPENAI_API_KEY` - OpenAI API 金鑰
- [ ] `OPENAI_ORGANIZATION` - OpenAI 組織 ID (可選)
- [ ] `OPENAI_REQUEST_TIMEOUT` - 請求超時時間 (預設 30 秒)
- [ ] `APP_KEY` - Laravel 應用程式金鑰
- [ ] `APP_ENV` - 環境設定 (local/production)
- [ ] `APP_DEBUG` - 除錯模式 (true/false)

### 資料庫設定
- [ ] SQLite 資料庫檔案存在 (`database/database.sqlite`)
- [ ] 所有遷移檔案已執行 (`php artisan migrate`)
- [ ] 資料庫權限正確設定
